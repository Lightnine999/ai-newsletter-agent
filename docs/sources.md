# 자료를 가져오는 다섯 길

| 길 | 예 | 장점 | 단점 | 이 프로젝트 |
|----|----|------|------|-------------|
| 1. RSS/Atom 피드 | 회사 블로그, 매체 피드 | 무료·안정적, 제목·링크·시각이 구조화돼 있음 | 본문이 짧거나 없음, 피드가 없는 곳도 있음 | **씀** (주력) |
| 2. 공개 API | Hacker News Algolia, arXiv | 필터·점수(추천 수)까지 받음 | 소스마다 형식이 다름, 호출 제한 | **씀** (HN: 추천 50+) |
| 3. 웹 스크래핑 | trafilatura로 기사 본문 추출 | 피드 없는 곳도 가능, 본문 확보 | 사이트 구조가 바뀌면 깨짐, 약관·차단 이슈 | **본문 추출에만 씀** (report 단계) |
| 4. 뉴스 API (유료 집계) | NewsAPI 등 | 한 번에 수천 매체 | 유료·무료 등급 제한, 품질 들쭉날쭉 | 안 씀 |
| 5. 검색 API | Google/Bing/Exa 검색 | 키워드로 넓게 | 비용, 최신순 보장 약함, 광고성 결과 | 안 씀 |

RSS로 넓게 받고, 커뮤니티 신호는 HN API로 보태고, 고른 5건만 스크래핑으로 본문을 가져와요.
비싸고 깨지기 쉬운 작업은 맨 마지막에 최소한으로만 해요.

## 관문 (`newsletter/sources.py`의 `gate`)

들어온 기사는 아래 순서로 걸러요. 어디서 몇 건이 떨어졌는지 로그에 남겨요.

1. **차단 도메인** — 보도자료 재배포 사이트 등
2. **신선도** — 36시간보다 오래되면 탈락
3. **제목 길이** — 15자 미만이면 탈락
4. **AI 관련성** — 제목·설명에 AI 키워드가 없으면 탈락
5. **중복** — 같은 URL이나 같은 정규화 제목은 하나만

실제 실행 예 (2026-10-28): 원본 2,325건 → 통과 42건 (오래됨 2,272 / 주제 밖 10 / 짧음 1).
피드 하나가 막혀도(이날 VentureBeat 429) 나머지로 계속 진행하고, 통과가 5건 미만이면 실패로 멈춰요.
